# Documentation Guide for AI Agents

## When to Create Documentation

Create documentation during development when you:
- Implement a new feature or architectural change
- Fix a significant bug or resolve a complex issue
- Add deployment configurations or operational procedures
- Optimize performance or refactor core components
- Integrate with external systems or services

## Documentation Structure

Choose the appropriate category based on document type:

- **`01-getting-started/`** - Quick start guides and installation tutorials
- **`02-architecture/`** - System design, technical decisions, and architectural patterns
- **`03-guides/`** - Step-by-step instructions for deployment, configuration, or integration
- **`04-operations/`** - Maintenance procedures and troubleshooting solutions
- **`05-reference/`** - API specifications and configuration references

## How to Create Documentation

1. **Select a template** from `_templates/` directory based on document type
2. **Copy the template** to the appropriate category subdirectory
3. **Fill in the YAML frontmatter** with complete metadata (title, description, tags, etc.)
4. **Follow the template structure** - each template provides detailed sections and formatting examples
5. **Update the index** - add your document link to the relevant `README.md`

For detailed writing guidelines, formatting rules, and contribution standards, refer to the templates in `_templates/` and the comprehensive guide in `CONTRIBUTING.md`.
